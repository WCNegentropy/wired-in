# wired-in-dashboard

![TypeScript](https://img.shields.io/badge/TypeScript-blue) ![react](https://img.shields.io/badge/react-green)

A web application built with TypeScript and react.

## Tech Stack

- **Language:** TypeScript
- **Framework:** react
- **Database:** None
- **Runtime:** node

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm 8+

### Installation

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Run tests
pnpm test
```
